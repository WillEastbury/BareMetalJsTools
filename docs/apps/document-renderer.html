HTML in. Real PDF out.

A dependency-free JavaScript renderer: browser HTML layout, rasterized page artwork, and a searchable text layer written into a real PDF file.

No print dialog. No PDF libraries.

The renderer creates an application/pdf Blob in JavaScript. Page artwork is rasterized; text is layered for search and selection.
